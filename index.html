Knowledge Hub. Quick Start Guide.

Focus on what matters. We’ll handle the rest.

⚙

Section 1 — The Basics

Creating a Task
Click the + New Task button in the header (or press N). Fill in the mandatory fields: Title, Category, and Start & End Dates. Optionally set Urgency and Status before saving.
Task Categories
Project — A long-running goal or initiative.  Things to Do — Personal tasks and reminders.  Action Item — Something that needs immediate attention.
Status Definitions
⏱ Pending Not yet started — the task is queued.
⚡ In Progress Actively being worked on right now.
✓ Completed Done. Task moves out of active views.
Urgency Levels
Four levels: Low → Medium → High → Critical. Urgency is shown as a coloured badge on every card and can be used as a filter.
Sub-Tasks
Click ➕ Sub-Task on any Kanban card to break a task into smaller steps. Each sub-task has its own title, description, dates, and status. Progress is shown as a ring on the parent card.
🗺

Section 2 — Dashboard Navigation

My ProctoAct Calendar (Gantt View)
A week-by-week Gantt grid showing how long each task spans across a Monday–Sunday calendar. Each task bar is colour-coded by category. Use the month & year selectors to navigate. Only Pending and In Progress tasks appear here.
My ProctoAct Roadmap
A horizontal scrolling deck of cards showing all your active Projects, To-Dos, and Actions. Cards are sorted by end date so the most urgent always appear first. Each card shows timeline fill, days remaining, and progress.
Kanban Board (3 Columns)
The main workspace. Three columns — Pending, In Progress, and Completed — show all your tasks as cards. Click any card to expand sub-tasks, or use the action buttons to edit, close, or move it to the Recycle Bin.
Recycle Bin
Deleted or closed tasks go here. Open it from the ⋮ More Options menu. You can restore tasks back to the board or permanently delete them.
⚡

Section 3 — Power-User Features

Drag & Drop (Roadmap)
Click and hold any Roadmap card, then drag it into the In Progress or Completed drop zone that appears at the bottom of the roadmap. Release to update the task status instantly — no editing required.
Filtering & Search
Use the search bar to find tasks by name. Use the Category and Urgency dropdowns to narrow results. All views — Kanban, Calendar, and Roadmap — sync together and show only the matching tasks.
Backup & Restore
Open ⋮ More Options and click Export to download your full task list as a .json file. Use Import to restore it on any device — useful as a manual backup.
Light & Dark Mode
Toggle between themes using the ☼ / ☾ switch in the header. Your preference is saved automatically and persists across sessions.
Keyboard Shortcuts
N New Task    F Focus Search    Esc Close any modal
Print & User Manual
Click the Download / Print PDF button in the footer of this guide to open the browser print dialog — choose Save as PDF to keep a copy, or send directly to a printer.
📊

Section 4 — Status Reporting & PDF Exports

Open the Full Summary Report
Click ⋮ More in the header, then choose 📊 Summary Report. A modal opens showing all tasks grouped by status — Overdue, In Progress, Pending, and Completed — each in its own colour-coded section with timeline, progress, urgency, and KPI markers.
Export a PDF Report
Inside the Summary Modal, click 🖶 Export PDF Report to generate a clean, print-ready PDF of that status list — including task title, category, timeline, progress %, and urgency badges. Useful for sharing with your team or keeping an offline record.
Smart Sorting & Indicators
Tasks inside the report are sorted chronologically by start date. ⭐ KPI badges, ∞ TBD open-end-date markers, and sub-task progress ratios are all carried over into the summary and the exported PDF automatically.

Section 5 — ProctoAct Task Notes

Opening a Note
Every task card on the Kanban board (across Pending, In Progress, and Completed columns) displays a 📝 Add Note button in its action row. Clicking it opens a focused rich-text canvas bound exclusively to that task — without triggering the Task Detail view or any other modal. Once a note has been saved, the button highlights in sky-blue and reads 📝 Note so you can see at a glance which tasks have notes attached.
Rich-Text Formatting Toolbar
The editor provides a full inline toolbar with the following controls:

B Bold  •  I Italic  •  U Underline
Font Family — Inter, Arial, Georgia, Courier New, Times New Roman.
Font Size — Small (12 px), Medium (15 px), Large (20 px), XL (26 px).
• Bullet List — creates a standard unordered list inside the canvas.
✕ Clear — strips all formatting back to plain text.

All formatting is stored as HTML so it renders exactly as written on every re-open. Toolbar buttons reflect live active state while you type or select text.
Saving & Persistence
Click Save Note to commit your content. A ✓ Saved successfully indicator flashes briefly to confirm. Each note is stored in localStorage under the key proctoNotes_[taskId] — a dedicated, isolated namespace that is completely separate from the core task database (proctoact_v1). This keeps all Backup & Export operations lightweight, secure, and unaffected by note data.
Closing Without Saving
Click the × button, press Esc, or click outside the modal to close the editor without saving. Any unsaved changes are discarded; the previously saved note content remains intact in storage.
Data Safety & Backup Note
Notes are stored under their own proctoNotes_ keys and are not included in the JSON backup exported via Export Backup. This is intentional — it keeps backup files lean and focused on task structure. Clearing browser site data will erase notes alongside tasks; keep regular JSON exports as your primary recovery point.

Section 6 — ProctoAct Note NEW

What is ProctoAct Note?
ProctoAct Note is a dedicated Document Management Hub — a fullscreen workspace separate from the main dashboard where you can create, organise, and manage rich-text Notes and Meeting Minutes linked directly to your active tasks. Unlike the inline per-task notes, ProctoAct Note gives you a persistent, scrollable document library that survives across sessions.
Accessing ProctoAct Note
Click the ☰ VIEWS tab pinned to the right edge of the screen at any time. A slide-in Workspace Switcher panel opens. Click 📝 My ProctoAct Note to enter the Document Hub. Click 💻 My ProctoAct App to return to the main dashboard. The Esc key closes the switcher panel.
Creating a New Note
Click 📝 Add New Note in the top-right header. A popup form opens where you configure the document before creating it:

• Document Type — choose Notes for general write-ups or Meeting Minutes for structured meeting records.
• Accent Color — pick one of 6 glowing color tokens (Emerald, Sky Blue, Amber, Violet, Crimson, Teal) to visually distinguish the note card.
• Subject — either Link Task (connects the note to an active In Progress or Pending task from your dashboard) or Custom (free-text subject).
• Sub-Subject / Description — a short descriptor, e.g. "Meeting minutes with ABC Sdn Bhd".

Click Create Note → to add it to the library and open the editor instantly.
Dual-Pane Layout
The Document Hub uses a two-column layout. The left sidebar lists all your active note cards sorted by newest first — each card shows the accent color, document type badge, sub-subject title, linked task or custom subject, and creation timestamp. Click any card to open it in the right workspace. The right panel stays clean ("No note selected") until you select or create a note.
Writing & Formatting
The editor provides a full rich-text toolbar: B Bold, I Italic, U Underline, text alignment (left / center / right), font family (Inter, Arial, Georgia, Courier), font size (S / M / L / XL), bullet lists, and clear formatting. You can also update the document type, accent color, linked task, and sub-subject at any time from the metadata panel above the toolbar — changes auto-save silently.
Saving & Navigating
Click 💾 Save in the toolbar to commit all changes and return to the note list. Click ← Back to return to the list without triggering a manual save (auto-save still captures recent input). The app also auto-saves silently on every keystroke with a 600 ms debounce — the ✓ Saved indicator in the header confirms each commit.
Recycle Bin & 7-Day Auto-Purge
Click 🗑 Delete in the toolbar to send the active note to the Recycle Bin — it is not permanently deleted immediately. Open the 🗑 Recycle Bin (top-right header) to see all trashed items with their deletion date and a countdown showing how many days remain before auto-purge. Each trashed note has a ↩ Restore button to reinstate it and a ✖ Delete button for immediate permanent removal. On every app launch, notes deleted more than 7 days ago are automatically and permanently removed with no action required.
Data Persistence
All ProctoAct Note documents are stored under a dedicated localStorage key: proctoSuiteGlobalNotesCollection. This namespace is completely isolated from the core task database (proctoact_v1), ensuring that your notes and your tasks never interfere with each other. Clearing browser site data will erase both — export your JSON backup regularly as your primary recovery point.

⚠  Step 1 — Mandatory
INSTALLATION — Do This First

Make sure the very first thing you do is install the app by clicking the "⬇ Install App" button in the top-right header. This ensures full offline access and gives ProctoAct its own dedicated workspace — independent of your browser session. Once installed, the app is accessible from your desktop or taskbar and works without an internet connection.

1. Introduction

ProctoAct App is a self-contained, browser-based project and task management dashboard. It combines a Gantt-style calendar, a roadmap summary, and a Kanban board into a single Progressive Web App (PWA) that requires no server, no login, and works fully offline after installation. All data is stored locally in your browser.

2. Dashboard — KPI Tiles

The top row displays four real-time KPI tiles giving you an instant snapshot of your workload:

  • Pending — Tasks queued but not yet started.
  • In Progress — Tasks actively being worked on. These appear in the Calendar and Roadmap views.
  • Completed — Tasks marked Done. Archived from active views but retained for reporting.
  • Overdue — Tasks whose end date has passed without completion. Flagged with a red pulse animation across all views.

Clicking any tile filters the Kanban board to show only that status group.

3. My ProctoAct Calendar

A compact Gantt-style timeline that visualises all active Pending and In Progress tasks across a Monday-to-Sunday weekly grid. Each coloured bar represents one task, spanning from its Start Date to its End Date.

Reading the Grid
  • Each row is one week (Mon → Sun).
  • Bars spanning multiple weeks show a flat edge to indicate continuation.
  • The today column is highlighted with a blue top-border.
  • Hover a bar for a tooltip with status, urgency, category, and days remaining.
  • Click a bar to jump to that task on the Kanban board.
Month Navigation
  • Use ❮ / ❯ arrows to go to the previous or next month.
  • Use the Month / Year dropdowns to jump to any month directly.
  • Click "Today" to return to the current month. The nav bar glows blue when viewing the current month.
  • Click "Collapse" to hide the grid; click "Expand" to restore it.
Tip: Tasks are only visible in months they are scheduled in. Make sure all tasks have both a Start Date and an End Date for full Calendar visibility.
4. My ProctoAct Roadmap

A horizontally scrollable row of summary cards — one per active Pending or In Progress task. Unlike the Calendar, this section shows your full active pipeline regardless of selected month. Cards are sorted with overdue tasks first, then by nearest due date.

  • Large day number — Due date day. Overdue tasks pulse red.
  • Progress bar — How far through the task's scheduled window you are.
  • Days-left chip — Remaining days or overdue duration.
  • Click any card to jump to the matching Kanban task.
5. Task Management
Creating a New Task

Click "✚ New Task" (top-right header). Fill in Title, Description, Category, Urgency, Start Date, End Date, and Status, then click "Save Task". The task appears immediately across all views.

6. Task Categories

ProctoAct uses a three-tier category system:

CategoryColourIntended Use
Project Electric Blue Formal milestones, deliverables, or initiatives with a defined scope and timeline. Use for work contributing to a named project or workstream.
Things to Do Soft Amber General to-do items, administrative tasks, reminders, or recurring responsibilities that are not part of a formal project.
Action Item Emerald Green Specific actions from meetings or decisions requiring follow-up. Typically short-lived and outcome-focused — e.g. "Send report to stakeholder by Friday."
Urgency Levels
  • Low — Complete when capacity allows.
  • Medium — Standard priority; complete within the scheduled window.
  • High — Requires focused attention; do not delay.
  • Critical — Must be resolved immediately. Solid red badge in all views.
7. Data & PWA
  • 📥 Export — Download all tasks as a .json backup. Do this regularly.
  • 📤 Import — Restore from a backup. Warning: overwrites all existing tasks.
  • 📋 User Manual — Opens this document for print or "Save as PDF".
  • ⬇ Install App — Installs ProctoAct as a PWA for offline use with a dedicated app window.
Important: Clearing browser site data erases all tasks. Keep regular JSON exports as your recovery point.
